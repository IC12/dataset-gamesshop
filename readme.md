# 📊 Análise de Vendas de Consoles

## 🏢 Sobre o Projeto
Este é um projeto experimental e prático focado em manipulação de prompts e análise de dados. O objetivo é extrair insights a partir de arquivos CSV contendo informações sobre vendas de consoles móveis em diferentes marketplaces.

A empresa analisada fabrica consoles, mas não realiza a venda diretamente ao consumidor. A distribuição e comercialização são feitas por terceiros, com alcance global.

## 🔍 O Que Foi Feito?
Foram realizadas as seguintes análises:

1️⃣ Resumo de Vendas por País
📌 Analisamos os dados para identificar quantos consoles foram vendidos em cada país.

2️⃣ Média da Faixa Etária dos Compradores
📌 Calculamos a idade média dos consumidores por país para entender o perfil do público-alvo.

3️⃣ Produtos Mais Populares em Cada País
📌 Identificamos qual produto teve mais vendas em cada país com base nos registros disponíveis.
